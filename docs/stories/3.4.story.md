## Story

**As a** user,
**I want** to click on nodes in the network graph to navigate directly to detailed views,
**so that** I can seamlessly move between visual overview and focused work.

## Acceptance Criteria

1. Clicking task nodes opens task detail view with context preservation
2. Clicking tag nodes applies filter showing all tagged tasks
3. Double-clicking nodes highlights connected relationships for focused exploration
4. Right-click context menu offers quick actions (edit, delete, add tags)
5. Navigation maintains graph state so users can return to previous view
6. Breadcrumb navigation shows path from graph to current detail view
7. URL routing supports direct linking to specific graph configurations

### vis-network Event API Reference

[Source: vis-network 9.x docs; confirmed in Story 3.1 integration]

```javascript
// Click event — fires once per click; params.nodes is array of clicked node IDs
network.on('click', function (params) {
    if (params.nodes.length === 0) return;  // canvas click, ignore
    var nodeId = params.nodes[0];
    // ...
});

// Double-click event — fires on second click; does NOT re-fire click for same action
network.on('doubleClick', function (params) {
    if (params.nodes.length === 0) return;
    var nodeId = params.nodes[0];
    var connectedNodes = network.getConnectedNodes(nodeId);
    var connectedEdges = network.getConnectedEdges(nodeId);
    network.selectNodes(connectedNodes);
    network.selectEdges(connectedEdges);
});

// Right-click event — params.event is the native MouseEvent
network.on('oncontext', function (params) {
    params.event.preventDefault();
    if (params.nodes.length === 0) return;
    var nodeId = params.nodes[0];
    // position context menu at params.event.clientX, params.event.clientY
});
```

**Click/doubleClick timing concern**: vis-network fires `click` on the FIRST mouse click of a double-click sequence. Use a `clickTimeout` pattern to delay single-click navigation by 250ms and cancel it if `doubleClick` fires:

```javascript
var clickTimeout = null;

network.on('click', function (params) {
    if (params.nodes.length === 0) return;
    var nodeId = params.nodes[0];
    clickTimeout = setTimeout(function () {
        // perform navigation here
    }, 250);
});

network.on('doubleClick', function (params) {
    if (clickTimeout) { clearTimeout(clickTimeout); clickTimeout = null; }
    // perform highlight here
});
```

### URL-Based Filtering (AC7)

In `graph-viewer.js`, replace the hardcoded fetch URL:

```javascript
// Before:
fetch('/api/graph/data/', { ... })

// After:
var graphParams = new URLSearchParams();
var pageParams = new URLSearchParams(window.location.search);
['filter_tag', 'filter_status'].forEach(function (key) {
    var val = pageParams.get(key);
    if (val) graphParams.set(key, val);
});
var apiUrl = '/api/graph/data/';
if (graphParams.toString()) { apiUrl += '?' + graphParams.toString(); }
fetch(apiUrl, { ... })
```
